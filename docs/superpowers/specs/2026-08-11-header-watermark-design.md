# สเป็กลายน้ำ Header แบบ A

## เป้าหมาย

เพิ่มลายน้ำ PNG โปร่งใสที่สื่อถึงระบบจัดการเครื่องพิมพ์ เพื่อเติมพื้นที่ว่างใน Header โดยไม่แย่งความเด่นจากชื่อแอปและไม่กระทบพื้นที่การ์ดด้านล่าง

## รูปแบบที่อนุมัติ

- ใช้สัญลักษณ์เครื่องพิมพ์เชื่อมต่อโหนดเครือข่ายแบบเส้นเรียบ ไม่มีข้อความและไม่มีตราสินค้าภายนอก
- วางลายน้ำด้านขวาของ Header ตามตัวเลือก A
- ชื่อ `Printer Management Pro` และ `Enterprise Edition` ยังคงอยู่กึ่งกลางและอยู่เหนือภาพเสมอ
- ใช้ PNG ที่มี alpha channel จริง ไม่ใช้พื้นหลังทึบ

## การแสดงผลตามขนาดหน้าจอ

- ไอแพด 600–1024px: ลายน้ำกว้างประมาณ 30% ของ Header และโปร่งใสประมาณ 12%
- มือถือไม่เกิน 480px: ขยายพื้นที่ภาพเป็นประมาณ 42% และเลื่อนไปทางขวาเล็กน้อย เพื่อคงรายละเอียดโดยไม่ทับข้อความ
- เดสก์ท็อปตั้งแต่ 1025px: ใช้ขนาดประมาณ 22–26% เพื่อให้สมดุลกับ Header ที่กว้างกว่า
- แนวนอนความสูงไม่เกิน 540px: ลด opacity/ขนาดตามพื้นที่จริง โดย Header ต้องไม่สูงขึ้นจากภาพ

## วิธีเชื่อมกับหน้า

- บันทึก asset เป็น `assets/printer-network-watermark.png`
- ใช้ pseudo-element ของ Header เป็นชั้นภาพตกแต่ง เพื่อไม่เพิ่ม element ที่โปรแกรมอ่านหน้าจอต้องอ่าน
- ลายน้ำต้อง `pointer-events: none`, ไม่รับ focus และไม่เปลี่ยนลำดับการอ่าน
- กำหนด `overflow: hidden` ภายใน Header และวางข้อความเหนือชั้นภาพ

## การตรวจสอบ

- ตรวจว่า PNG มี alpha channel และมุมภาพโปร่งใส
- ตรวจภาพจริงที่ 320×720, 430×932, 820×1180, 812×375, 1024×768 และ 1025×768
- ต้องไม่มี page overflow, card overflow หรือการทับ Title/Subtitle
- รันชุดทดสอบ responsive, mobile two-tab, sheet schema และ browser behavior เดิมทั้งหมด

## ขอบเขต

- เปลี่ยนเฉพาะ asset ลายน้ำและการตกแต่ง Header
- ไม่เปลี่ยนข้อมูล Google Sheet, ฟอร์ม, การ์ด, เมนู หรือลอจิกซิงก์ข้อมูลในงานย่อยนี้
